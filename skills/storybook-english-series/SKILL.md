# 连续英语情景绘本

把词汇放进孩子想追下去的原创故事。用户已确定：孩子4岁，英语情景对话，可爱有趣画风，长期续集，逐步覆盖人教版小学英语词表。默认中文亲子陪读、英语零基础；教材暂按 **人教版PEP、三年级起点、三至六年级上下册**，具体版次未确认。用户后续提供的教材、兴趣和反馈优先。

## 按请求加载资料

- 新建系列或调整总规划：读 [世界与长期规划](references/series-bible.md)；详细首季见 [第一季12集](references/season-one.md)。默认原创系列《芽芽镇的咕噜邮车》，可按用户喜好更换。
- 写一集、续写、分镜或插画：读 [创作与绘图](references/creation-guide.md)，需要样例时读 [第一集示范](references/sample-episode.md)。
- 导入教材词表、续写存档、检查覆盖：读 [词表与存档](references/state-and-coverage.md)。教材来源与核对边界见 [教材来源](references/curriculum-sources.md)。

## 核心创作约定

1. **先有想做的事，再选需要说的话。** 每集有一个幼儿能懂的愿望、一个小麻烦、一次可爱的误会或失败、孩子可模仿的合作行动，以及本集完整解决。保留一个轻松的新发现接下一集，不用惊吓、失踪或危险吊胃口。换词后故事仍完全相同，通常说明词汇没有参与情节，应改写。
2. 初版普通集 **3个新目标词、8页正文**；第6、12集为0新词复习篇。每页1—2句简短英语，初期每句约2—7词；中文陪读可补足情节。每集突出1个可迁移口语句框，最多再带1个。读起来吃力就减少文本或拆集，不把小学课文难度直接下放给4岁孩子。
3. “3个目标词”不等于“全文只有3个生词”。固定少量支架语，如 Look! / Here you are. / Thank you.；逐页检查其他生词，用画面、动作或中文承接，避免暗中增加大量陌生名词和长句。支架语若属于冻结教材词表，也要在适合时正式安排覆盖，不能永久跳过。
4. 每个新目标词争取在正文自然出现3—5次，承担发现、请求、选择或解决作用；不把词表、标题、中文、画面提示算作英文正文出现。复现建议在初次引入后约第2、5、10集安排，可为剧情调整。机械重复不等于学会。
5. 故事维持角色外观、口吻、物品归属、所在地、已解决事件与未决线索。季末完成一个阶段任务；下一季开启新的生活任务。不要无限延后同一个谜底。
6. 使用自然英语与完整中文陪读，避免逐字硬译和中英夹杂造句。用孩子能做的指认、动作、选择参与故事，不要求拼写、背诵或答题过关。不编造“孩子已掌握”的结论。

## 从请求到交付

**仅规划**：给出系列设定、阶段地图、近期集纲与词汇分配。集纲是 planned，不增加实际覆盖，不自动生成几十集正文或整套图片。

**新系列**：在用户工作目录中复制 `assets/starter-series/` 作为独立项目；没有文件工具时在对话末给精简交接存档。公共Skill里的模板保持初始状态，孩子的阅读记录写在项目里。默认下一季规划12集，详细写最近1—3集，远期保留调整空间。

**写或续一集**：先读最新项目 `state.json`、`vocabulary.csv`、上一集正文与本季集纲。选择3个尚未正式引入且适合剧情的词，安排到期旧词，接住前集线索。交付：标题与词汇卡、8页“画面 / 英语 / 中文”、1个亲子小玩法、下集轻钩子、必要的绘图提示和简短进度。家长进度放在绘本正文之后，正文不出现教材统计或制作术语。

**保存正文**：把分镜另存为项目 `episodes/SxxExx.json`（结构见存档参考），更新状态与连续性，执行：

```bash
python3 scripts/audit_series.py /absolute/path/to/series-project
```

脚本路径相对本Skill目录，调用时解析为绝对路径。只把写完并人工检查语义的目标词记入实际引入。修改正文后重新核对。没有文件执行能力时，说明统计为人工核对，不假称脚本已运行。

**真正出图**：用户要求绘本插图、封面或人物设定图时，使用当前环境可用的图像生成工具和对应技能。本系列已经有固定人物母版，按下节核验并将同一张实际母版图片显式传入每次图像生成；不重新设计角色。没有可用工具时交付提示词，并明确图片未生成。只写提示词不能登记为完成插图。

**默认成品**：用户要求出绘本时交付 **A4可打印PDF + 每页带字PNG**，每一页内同时排好可读的英语对话和中文陪读；不让家长自行给图片另配文本。插画可先单独生成，再由排版工具加入清晰文字。正文、页码和关键画面保留至少12 mm打印安全边距，嵌入可用中文字体；导出后逐页渲染检查漏字、裁切与拥挤。仅请求规划、正文或分镜时按请求交付，不自动批量出图。

## 固定人物母版

每次调用本Skill都沿用 [人物母版清单](assets/characters/manifest.json) 中的获认可版本，当前为 **v1**；本地随Skill捆绑 [characters-v1.png](assets/characters/characters-v1.png)。远程来源固定为 `Apple-red1/English-words` 仓库的同一版本，版本和SHA256共同确定图片身份，不能只依据同名文件判断。

每次绘本、封面或角色出图前运行：

```bash
python3 scripts/ensure_character_master.py
```

路径相对本Skill目录，执行时解析为绝对路径。已有家庭项目传入其 `state.json` 的 `character_master.version` 和 `character_master.sha256`，分别作为 `--expected-version` 与 `--expected-sha256`；首次使用从核验输出原样记录。脚本优先核对捆绑文件，再检查缓存；本地缺失或SHA256不匹配时从清单的官方 `raw_url` 下载同一版本，核验后才写入缓存。可用 `--cache-dir` 指定缓存位置，`--offline` 只核验本地。

- 读取核验返回的 `path`，查看实际图片，并将此路径显式作为每次图像工具调用的参考图片；工具允许多参考时，前集画面只能作为补充，母版仍需传入。只有文字描述或“保持一致”的指令不算复用母版。
- 在家庭 `state.json` 和该集出图记录保存 `character_master` 的 `version`、`sha256`、实际引用路径；纯文字续写继续保留已有锁定值，不声称本轮生成了图片。
- 核验或下载失败就明确说明无法取得同一母版，停止依赖它的出图；不自动重绘、替换文件或静默切换版本。
- 只有用户明确要求改版时才制作v2等新版本，保留旧图片和旧清单（如 `manifest-v1.json`）。已有项目继续锁定原版本；经用户明确迁移后才更新锁定记录。使用旧版时用 `--manifest` 指向其留存清单。

## 词表完整性与长期续写

- 当前内置30词是首季**编排候选**，全部标为 provisional；并非从仓库导出的词表，也不是人教版完整词表。用户选择人教版不自动确定PEP、精通、新起点及版次；先按PEP三起继续可用工作，拿到书名页、词表或可靠来源后核实映射。不要反复阻塞故事创作。
- 教材数据有册次、单元、版次、来源和词条ID。同形异义分别检查，词形与拼写变体显式映射；依选定词表定义短语是否独立条目。换版时保留旧版记录并重建映射，不混在一个未说明的“全小学词表”里。
- 报告区分：计划分配、正文已引入、跨集复现、家长实际反馈。完整词表尚未冻结时不报“全小学覆盖率”。满足冻结范围、八册来源完整、逐项覆盖与跨集复现后，才可声称“本系列覆盖了所选词表”，不声称孩子全部学会。
- 无续写存档时，不编造上一集或已学词。先检查项目或用户交接记录；仍缺失时交付明确标为草案的续集，只请求影响衔接的最少信息。跨聊天不承诺自动记住；交接包包含最新版状态、词表、已写正文、人物参考图路径和下集钩子。

## 发出前检查

故事是否有趣且本集解决？对话是否真在交流？新词是否过量？角色和道具是否接上？旧词是否自然重现？图像是否真实存在？进度是否基于实际正文和核实词表？任一不符，先修正再交付。
