# 第一集示范：会咕噜叫的盒子

这是可供正式稿采用的写作样例，尚未写入家庭初始存档。以下插画仅为分镜描述，没有生成图片。每页只朗读“连续朗读正文”这一栏，中文叙事自然接入英语人物对白，不另读一套译文。

目标词：**door 门、open 打开、box 盒子**。词汇为候选，具体教材位置待核。主句框：**Open …, please.** 支架语：Look! / A … / The …? / Yes! / Oh! / Hello!；通过画面、动作和上下文理解，不逐句重译。

| 页 | 画面 | 连续朗读正文 |
|---|---|---|
| 1 | 米米透过圆窗指向门外。一个大纸盒微微晃，盒底伸出一小截蓝色。团团拿着空饼干盘竖起耳朵。 | 米米透过圆窗指向门外：“Look! A box!”一个大纸盒正轻轻晃动，发出“咕噜、咕噜”的声音。团团摸摸自己的肚子：咦，我还不饿呀。 |
| 2 | 团团想看看盒子，却抱着饼干盘腾不出手；他看向米米，指着房门。 | 团团抱着空盘子，朝米米眨眨眼：“Open the door, please.”他猜，盒子里一定有块会打嗝的大饼干！ |
| 3 | 米米握住门把手，先确认团团站稳，再把门拉开；团团让出门边位置，盘子差点当成帽子举起来。 | 米米握住门把手，歪着脑袋确认：“The door?”团团已经把盘子举到头顶，赶紧点头：“Yes, the door!”门一开，“咕噜”声更清楚了。团团把盘子摆好，准备接住大饼干。 |
| 4 | 两人已在门廊。米米扶住盒身，团团面对盒盖，盘子放在旁边。 | 米米蹲下来扶住盒子，抬头对团团说：“Open the box, please.”盒盖忽然顶起一个小鼓包。团团瞪圆了眼睛：饼干也会长脑袋吗？ |
| 5 | 团团爪子停在盒盖上，回头确认。米米点头，两人一起揭开盖子；团团还把盘子准备在盒边。 | 团团的爪子停在盒盖上，回头问：“The box?”米米使劲点头：“Yes! Open the box!”一、二——他们一起把盖子慢慢抬起来。 |
| 6 | 一辆面包形蓝色小邮车从展开的纸盒坡道滑下来，圆灯闪一下。团团看见“面包”，举起盘子；邮车咕噜一声，团团停住，惊喜地挥爪。 | 一辆面包形的蓝色小邮车沿着纸盒坡道滑了下来。团团看见“面包”，又举起盘子。小邮车咕噜一声，团团的爪子停在半空：“Oh! Hello!”他笑着把盘子藏到背后，改成朝新朋友挥挥爪。 |
| 7 | 米米蹲下挥手，团团也向邮车挥爪。邮车灯光回应，车门边露出一封叶子形邀请。 | 米米蹲下身，朝邮车挥挥手：“Hello!”团团也跟着招呼：“Hello!”圆圆的车灯闪了一下，一封叶子形邀请从车门边滑出来——欢迎大家来芽芽镇野餐。 |
| 8 | 两位伙伴并排看邀请背面。红黄蓝三条飘带从车门里弹出来，轻轻落到团团头上；角色笑，颜色不标字。 | 米米和团团凑在一起看邀请背面。忽然，三条彩色飘带从车门里弹出来，轻轻落到团团头上。米米忍不住笑了：“Look!”红黄蓝的飘带围成小狮子的鬃毛。明明要做野餐路标，团团怎么先变成小狮子啦？ |

亲子小游戏：把一个玩具放进空盒子。家长说“Open the box, please.”，孩子可打开、指一指或交换角色；愿意时再接一个box或open，不用答题。
