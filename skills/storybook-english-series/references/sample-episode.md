# 第一集示范：会咕噜叫的盒子

这是可供正式稿采用的写作样例，尚未写入家庭初始存档。以下插画仅为分镜描述，没有生成图片。每页只朗读“连续朗读正文”这一栏，中文叙事自然接入英语人物对白，不另读一套译文。

目标词：**door 门、open 打开、box 盒子**。词汇为候选，具体教材位置待核。主句框：**Open …, please.** 支架语：Look! / A … / The …? / Yes! / Oh! / Hello!；通过画面、动作和上下文理解，不逐句重译。

|---|---|---|
| 1 | 米米透过圆窗指向门外。一个大纸盒微微晃，盒底伸出一小截蓝色。团团拿着空饼干盘竖起耳朵。 | “咕噜——咕噜——”门外响起奇怪的声音。<br>米米指着盒子喊：“Look! A box!”<br>团团摸摸肚子：“咦，我还不饿呀！” |

| 3 | 米米握住门把手，先确认团团站稳，再把门拉开；团团让出门边位置，盘子差点当成帽子举起来。 | 米米握住门把手，回头问：“The door?”<br>团团举起盘子：“Yes, the door!”<br>门开啦！团团差点给自己戴了顶“盘子帽”。 |
| 4 | 两人已在门廊。米米扶住盒身，团团面对盒盖，盘子放在旁边。 | 米米扶住盒子，笑着说：<br>“Open the box, please.”<br>盒盖鼓起小包。团团瞪圆眼睛：<br>“饼干也会长脑袋吗？” |
| 5 | 团团爪子停在盒盖上，回头确认。米米点头，两人一起揭开盖子；团团还把盘子准备在盒边。 | 团团扶着盒盖，回头问：“The box?”<br>米米点点头：“Yes! Open the box!”<br>一、二——两人一起抬起了盖子。 |
| 6 | 一辆面包形蓝色小邮车从展开的纸盒坡道滑下来，圆灯闪一下。团团看见“面包”，举起盘子；邮车咕噜一声，团团停住，惊喜地挥爪。 | 一辆蓝色小邮车滑了出来！<br>团团挥挥爪：“Oh! Hello!”<br>原来不是大饼干！他偷偷把盘子藏到背后。 |
| 7 | 米米蹲下挥手，团团也向邮车挥爪。邮车灯光回应，车门边露出一封叶子形邀请。 | 米米蹲下来，轻轻挥手：“Hello!”<br>团团也开心地说：“Hello!”<br>邮车闪闪灯，送出一封叶子形邀请：<br>欢迎大家来芽芽镇野餐！ |
| 8 | 两位伙伴并排看邀请背面。红黄蓝三条飘带从车门里弹出来，轻轻落到团团头上；角色笑，颜色不标字。 | 米米抬起头，笑着喊：“Look!”<br>红、蓝、黄三条飘带落在团团头上。<br>“嗷呜！我是来参加野餐的小狮子！”<br>野餐还没开始，小熊怎么先变小狮子啦？ |

亲子小游戏：把一个玩具放进空盒子。家长说“Open the box, please.”，孩子可打开、指一指或交换角色；愿意时再接一个box或open，不用答题。
